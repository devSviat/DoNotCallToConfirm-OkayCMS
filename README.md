# Модуль Do Not Call to Confirm для OkayCMS

Модуль додає чекбокс у кошик, щоб клієнти могли позначити, що їм не потрібно телефонувати для підтвердження замовлення. Це значення відображається в списку замовлень та в картці замовлення поруч із номером телефону.

## Можливості

- **Чекбокс у кошику** — клієнт може позначити «Не телефонувати для підтвердження замовлення» під час оформлення
- **Відображення в списку замовлень** — іконка (перекреслений телефон) біля замовлень, де клієнт обрав не дзвонити
- **Відображення в картці замовлення** — позначка «Не телефонувати» поруч із полем телефону в адмін-панелі

## Вимоги

- PHP 8.4+
- OkayCMS 4.5.3 (чиста або [форк](https://github.com/devSviat/OkayCMS))
- Перевірено на PHP 8.5 — на чистій OkayCMS 4.5.3 і на форку

## Встановлення

### Варіант 1: Скачування з GitHub

1. Скачайте останню версію модуля з [останнього релізу на GitHub](https://github.com/devSviat/DoNotCallToConfirm-OkayCMS/releases/latest).
2. Розпакуйте архів на сервері в каталог: `{OkayCMS_root}/Okay/Modules/`

### Варіант 2: Встановлення через Git

1. Виконайте команду в директорії `{OkayCMS_root}/Okay/Modules/Sviat`:
   ```bash
   git clone https://github.com/devSviat/DoNotCallToConfirm-OkayCMS.git DoNotCallToConfirm
   ```

### Результат встановлення

Шлях до модуля має бути таким:

```bash
{OkayCMS_root}/Okay/Modules/Sviat/DoNotCallToConfirm/
```

Після встановлення перейдіть в адмін-панель → Модулі → Знайдіть «Не звонить» → Натисніть «Встановити».

## Використання

1. Після встановлення модуля чекбокс «Не телефонувати для підтвердження замовлення» з’являється в кошику під полем коментаря до замовлення.
2. Якщо клієнт позначить чекбокс і оформить замовлення, у списку замовлень біля такого замовлення відображатиметься іконка перекресленого телефону.
3. У картці замовлення (адмін-панель) поруч із номером телефону буде показано позначку «Не телефонувати».

Модуль не потребує додаткового налаштування — після встановлення він одразу працює.
